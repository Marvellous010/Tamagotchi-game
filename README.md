# 🐦 Tamagotchi Game - Angry Birds Edition

Een leuke browser-gebaseerde Tamagotchi game met een Angry Birds thema!

## 🎮 Over het Spel

Dit is een virtueel huisdier spel waarin je moet zorgen voor je Tamagotchi (een Angry Bird karakter). Houd je huisdier gelukkig door te zorgen voor drie belangrijke behoeften:

- **🍔 Honger** - Voer je Tamagotchi om honger te stillen
- **💤 Slaap** - Laat je Tamagotchi rusten om energie op te laden
- **⚽ Plezier** - Speel met je Tamagotchi om verveling te voorkomen

## 🚀 Hoe te Spelen

1. Open `Tamagotchihome.html` in je browser
2. Klik op **"Start Spel"** om te beginnen
3. Gebruik de knoppen om voor je Tamagotchi te zorgen:
   - **Voeren** - Verhoogt honger meter
   - **Spelen** - Verhoogt plezier meter
   - **Rusten** - Verhoogt slaap meter
4. Let op! De meters dalen automatisch over tijd
5. Als een meter op 0% komt, is het **Game Over**!

## 🛠️ Technologieën

- **HTML5** - Structuur
- **CSS3** - Styling en animaties
- **JavaScript** - Game logica en interactiviteit

## 🎵 Features

- Achtergrondmuziek tijdens het spelen
- Geluidseffecten bij knoppen
- Dynamische afbeeldingen gebaseerd op Tamagotchi's stemming
- Gedachtenbubbels die de stemming van je huisdier tonen

## 📝 Spelregels

- Elke 2 seconden dalen de meters met een willekeurige waarde (1-15%)
- Elke actie verhoogt de bijbehorende meter met 5%
- Het spel eindigt wanneer een van de meters 0% bereikt
